БИЛЕТ 01

Класс и объект

Простыми словами
Класс — как шаблон карточки товара, объект — конкретная карточка.

Что написать на экзамене

ООП представляет программу как систему взаимодействующих объектов. Класс — тип, описывающий поля и методы. Объект — экземпляр типа с собственным состоянием. Например, Product a, b; создаёт два объекта одного класса.

Простыми словами

Что написать на экзамене

Абстрактный класс имеет хотя бы одну виртуальную функцию, которая остаётся чисто виртуальной. Её объявляют с = 0. Нельзя создать отдельный объект абстрактного типа, но указатель или ссылка разрешены. Поля, конструкторы и обычные методы тоже допустимы.

struct Shape {
    virtual double area() const = 0;
    virtual ~Shape() = default;
};
struct Square : Shape {
    double area() const override { return 4.0; }
};

Не перепутай: override попросит компилятор проверить совпадение метода.

БИЛЕТ 22

Ошибки и исключения

Простыми словами
Если функция не может продолжать работу, она может передать ошибку тому, кто умеет её обработать.

Что написать на экзамене

Ошибки обозначают кодом, специальным результатом или исключением. optional обозначает отсутствие значения, expected в C++23 — результат или ошибку. throw выбрасывает исключение, try оборачивает код, catch обрабатывает. Обычно ловят по const-ссылке, более конкретные типы ставят первыми. При раскрутке стека уничтожаются созданные локальные объекты; на этом работает RAII.

try { throw std::runtime_error("error"); }
catch (const std::exception& e) { /* обработка */ }

Не перепутай: assert проверяет внутренние предположения, а не пользовательский ввод.
